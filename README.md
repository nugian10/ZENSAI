## Price ladder (per wallet, locked in the contract)

| Mint # | Price |
|---|---|
| #1 FREE | Agent ID only, 1/wallet (`useFree`) |
| #2–10 | 0.0002 BNB each |
| #11–20 | 0.0004 BNB each |
| #21–30 | 0.0008 BNB each |

Max 30/wallet. **Bulk mint 1–30 in ONE transaction** — `mint(uint256 quantity, bool useFree)`. The free mint lands on the highest-priced slot in the batch.

Ladder math, stated exactly (on-chain pricing is by mint index: counts 0–9 → 0.0002, 10–19 → 0.0004, 20–29 → 0.0008):
- 30 paid mints = 10×0.0002 + 10×0.0004 + 10×0.0008 = **0.014 BNB**
- 30 with free mint = 0.014 − 0.0008 = **0.0132 BNB**
- **Max per wallet: 0.014 BNB for 30 paid mints (no free); 0.0132 BNB for 30 mints with the free mint.** Do NOT quote "max 0.0138" as the max — that figure was 29 paid + 1 free under a different counting (9×0.0002 + 10×0.0004 + 10×0.0008) and does not match either on-chain path. The contract is kept as built and tested (12/12 PASS); this is a copy correction only.
- Prices are **NOT shown on the site** (Bryan's rule). The agent reads `quoteBulk()` and shows the exact amount in the wallet confirmation before signing. The mint widget shows the live quote only after a wallet is connected and a quantity is chosen.

## $ZSAI bonus token

- `ZensaiToken.sol` — BEP-20/ERC-20, max supply **1,000,000,000**.
- Treasury **460,000,000** pre-minted to the owner at deploy; bonus pool **540,000,000** minted only by the NFT contract.
- **120,000 ZSAI per PAID mint**, automatically to the minter in the same mint transaction. Free mint earns 0.
- Max per wallet: 3,480,000 (29 paid + 1 free); 30 paid = 3,600,000.
- Worst case for the pool: 3,333 × 120,000 = **399,960,000** — inside the 540M pool (140,040,000 headroom).
- **$ZSAI has no price, no liquidity pool, and no guaranteed value.** Bonus only.
